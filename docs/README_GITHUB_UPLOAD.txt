WICHTIGER UPLOAD:

2. Im GitHub-Repository die alten Dateien löschen.
3. Den INHALT des entpackten Ordners hochladen.

5. GitHub: Settings > Pages
6. Source: Deploy from a branch
7. Branch: main
8. Folder: /root
9. Save
10. Einige Minuten warten.
