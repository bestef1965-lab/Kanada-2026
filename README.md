# Kanada 2026 – GitHub Pages

Diese Version zeigt Unterkünfte und Mietwagen direkt im Reiseführer, ohne eingebundene Buchungsdokumente.

## Veröffentlichung
1. Den Inhalt dieses Ordners in das Repository `Kanada-2026` hochladen.
2. GitHub: **Settings → Pages**.
3. **Deploy from a branch**, Branch **main**, Ordner **/(root)** wählen.
4. Speichern und die Veröffentlichung abwarten.
