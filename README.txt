Netlify Upload:
1. ZIP entpacken.
2. Bei Netlify einloggen.
3. Add new site > Deploy manually.
4. Den entpackten Ordner 'Kanada_Reisefuehrer_2026_Premium_Netlify' hochladen.
5. Netlify erzeugt danach den Website-Link.

Hinweis:
Die Website ist eine statische Seite. Checklisten, Favoriten und Notizen werden lokal im Browser gespeichert.
